# NestJS Authentication Backend

This project is a **back-and-forth** built using [NestJS](https://nestjs.com/) and [TypeORM](https://typeorm.io/)With a PostgreSQL database.

Provides user registration, login, token management (Access/Refresh), profile updates, and account logout/deletion.

---
## 🚀 Features
- New user registration with password encryption using `bcrypt`.

- Login with an Access Token and a Refresh Token.

- Store encrypted Refresh Tokens in the database.

- Renew tokens using Refresh Tokens.

- Update user data (username).

- Log out with tokens cleared.

- Permanently delete account..

---
## 🛠️ Requirements
- Node.js
- PostgreSQL
- npm
